# qa_python
# Проект тестирования BooksCollector - финальный проект 4 спринта "Юнит-тестирование"

В рамках проекта были написаны автотесты для класса `BooksCollector`.

## Покрытые методы

Реализованы тесты для следующих методов:

- `add_new_book`
- `set_book_genre`
- `get_book_genre`
- `get_books_with_specific_genre`
- `get_books_genre`
- `get_books_for_children`
- `add_book_in_favorites`
- `delete_book_from_favorites`
- `get_list_of_favorites_books`

## Описание тестов

- Проверка добавления трех книг в словарь books_genre 
- Негативная проверка добавления книги с пустым названием и с длинным названием (больше 40 символов)
- Проверка установления жанра, если книга есть в словаре books_genre
- Проверка, что метод get_book_genre возвращает жанр книги по ее названию
- Проверка вывода книги с определенным жанром
- Проверка, что метод get_books_genre выводит текущий словарь books_genre
- Проверка, что метод get_books_for_children возвращает книги, которые подходят детям (без возрастного рейтинга)
- Проверка, что метод add_book_in_favorites добавляет книгу в избранное
- Проверка, что метод delete_book_from_favorites удаляет книгу из избранного
- Проверка, что метод get_list_of_favorites_books получает список избранных книг

## Особенности

- Использована параметризация тестов для проверки разных входных данных
- Каждый тест независим и использует отдельный экземпляр класса

## Команда для запуска теста: pytest -v
